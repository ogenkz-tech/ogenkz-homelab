# Homer Dashboard

## 📝 Deskripsi
Homer adalah *homepage* statis dan sangat ringan yang menyimpan semua daftar *bookmark* atau *shortcut* menuju ke layanan homelab lainnya.

## 🛠️ Konfigurasi Jaringan
- **Host IP**: `10.0.0.18`
- **Port**: `8081` (Diarahkan ke `8080` di dalam kontainer)
- **Image Docker**: `b4bz/homer:latest`
