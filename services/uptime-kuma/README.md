# Uptime Kuma

## 📝 Deskripsi
Tool *monitoring self-hosted* untuk memantau status perangkat dan layanan di jaringan secara terus-menerus. Jika ada VM atau kontainer yang mati, Uptime Kuma bisa mengirimkan notifikasi.

## 🛠️ Konfigurasi Jaringan
- **Host IP**: `10.0.0.18`
- **Image Docker**: `louislam/uptime-kuma:1`
